# Steal a Fossil

Jeu Roblox de Snaky, calqué sur Steal an Egg : cours sur la route préhistorique, arrache des blocs fossiles gardés par des dinos vivants, ramène-les dans ton parc, réanime-les et fusionne-les en hybrides.
